# FITLIGHT web

App web (PWA) per comandare le luci FITLIGHT Trainer di vecchia generazione dal telefono Android,
con la chiavetta USB originale collegata in OTG (WebUSB, Chrome per Android).

Funzioni: scelta luci, reazione casuale, sprint con intermedi, distanza sensore, filtro sole.
Tutto avviene sul telefono: nessun dato viene inviato in rete.
